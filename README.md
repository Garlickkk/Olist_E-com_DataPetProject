# Olist_E-com_DataPetProject
Анализ данных 100.000 заказов на бразильских маркетплейсах за 2016-2018 года

# Главный вопрос проекта
В каких сегментах сосредоточены опоздания доставки, как они связаны с оценками и повторными покупками и какой сегмент стоит выбрать для пилотного улучшения?

# Вопросы исследования
1)Какие регионы и маршруты дают наибольшее число просроченных заказов?

2)Где проблема систематическая, а где результат объясняется небольшим числом наблюдений или отдельным месяцем?

3)Насколько отличаются оценки и повторные покупки у покупателей с разным опытом доставки?

4)Какой сегмент взять в пилот и по каким метрикам оценивать результат изменения?

# Основные гипотезы 
1)Частота опозданий различается между регионами покупателей

2)Доставка между разными штатами чаще опаздывает, чем доставка внутри одного штата

3)У заказов с опозданием чаще встречаются оценки 1–2

4)После опоздания первой наблюдаемой доставки покупатели реже делают повторный заказ
